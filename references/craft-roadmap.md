## The 4 Tiers of Frontend Mastery

```
[ Level 4: Design Engineer / Polish Maestro ]
• Spring physics, optical alignment, custom token systems, high-density layouts, a11y focus traps
▲
[ Level 3: Architecture & Enterprise Systems ]
• Component composition (slots), design token pipelines, multi-theme engines, clean state management
▲
[ Level 2: Component & Layout Developer ]
• Flexbox / Grid layout mastery, responsive clamp() typography, semantic HTML5, form validation
▲
[ Level 1: Foundations ]
• Basic CSS, DOM manipulation, JS events, framework syntax (React/Vue/Svelte)
```

## Pre-Flight Self-Audit for Any Production Screen

1. **Semantic Structure:** Are you using `<main>`, `<nav>`, `<aside>`, `<header>`, `<article>` appropriately instead of infinite generic `<div>`?
2. **Keyboard Nav:** Can you tab through the entire page and interact with modals without touching your mouse?
3. **Typography Rhythm:** Is body line-height between `1.5` and `1.75`? Are headings tightened with negative letter-spacing?
4. **Resilience:** What happens if the backend API returns a 500 error or is delayed by 3 seconds?
